## 🚀 Установка

Просто скопируйте файл с функциями в свой проект или импортируйте его напрямую:

```python
from utils import seti, st, st2, z, log, getv, er, w, debug, d
```

> Требуется Python 3.6+ (используются f-strings).

---

## 🧩 Функции

### `seti(p)`
Выводит сообщение о начале настройки указанного параметра.

```python
seti("config")
# Seting  config ...
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `p` | `str` | Название настраиваемого параметра |

---

### `st()`
Выводит общее сообщение о запуске процесса.

```python
st()
# Starting...
```

---

### `st2(p)`
Выводит сообщение о запуске указанного процесса/компонента.

```python
st2("server")
# Starting  server ...
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `p` | `str` | Название запускаемого компонента |

---

### `z(p1, p2)`
Сообщает о запуске чего-либо какой-то версии.

```python
z("client", "1.0.0")
# client v1..0.0 started
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `p1` | `str` | Первое значение |
| `p2` | `str` | Второе значение |

---

### `log(p)`
Универсальный логгер. Просто печатает переданное значение.

```python
log("Hello, world!")
# Hello, world!
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `p` | `Any` | Сообщение для вывода |

---

### `getv()`
Возвращает строку с текущей версией библиотеки.

```python
version = getv()
print(version)
# 1-0-5
```

**Возвращает:** `str` — версия в формате `major-minor-patch`.

---

### `er(er)`
Выводит сообщение об ошибке с префиксом `E:`.

```python
er("Connection failed")
# E:  Connection failed
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `er` | `str` | Текст ошибки |

---

### `w(w)`
Выводит предупреждение с префиксом `W:`.

```python
w("Low memory")
# W:  Low memory
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `w` | `str` | Текст предупреждения |

---

### `debug(m)`
Выводит отладочное сообщение с префиксом `DEBUG:`.

```python
debug("Variable x = 42")
# DEBUG: Variable x = 42
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `m` | `str` | Отладочное сообщение |

---

### `d(fi)`
Сообщает об удалении файла.

```python
d("temp.txt")
# file temp.txt deleted
```

| Параметр | Тип | Описание |
|----------|-----|----------|
| `fi` | `str` | Имя удалённого файла |

---

## 💡 Пример использования

```python
from utils import st, seti, z, log, er, w, debug, d, getv

def main():
    log(f"Version: {getv()}")
    st()
    seti("database")
    z("client", "server")
    debug("Initialization complete")
    w("Cache is empty")
    d("old_log.txt")
    er("Something went wrong")

if __name__ == "__main__":
    main()
```

**Вывод:**
```
Version: 1-0-5
Starting...
Seting  database ...
client vserver started
DEBUG: Initialization complete
W:  Cache is empty
file old_log.txt deleted
E:  Something went wrong
```

---

## 📝 Заметки

- Все функции выводят данные в `stdout` через `print()`.
- Функции `er`, `w` и `debug` не прерывают выполнение программы — это просто обёртки над `print`.
- `d()` только **сообщает** об удалении файла, но **не удаляет** его физически.
- `getv()` возвращает жёстко заданную строку — не забудьте обновить её вручную при выпуске новой версии.
